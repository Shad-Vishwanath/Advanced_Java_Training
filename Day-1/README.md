## 1. Richest Customer Wealth 💰

### Problem Overview
This problem gives a 2D array where each row represents a customer and each column represents the money in their bank accounts. The goal is to find the wealth of the richest customer.

### Logic Used
The logic is simple and effective:
- Traverse each row one by one
- Calculate the total wealth of that customer by summing all account values
- Compare it with the current maximum wealth
- Update the maximum whenever a richer customer is found

### What I Learned
- How to traverse a 2D array
- How to calculate row sums efficiently
- How to track the maximum value during iteration
- Better understanding of nested loops

### Takeaway
This problem helped me get comfortable with matrix-based input and taught me how to solve problems step by step: calculate, compare, and update ✅

## 2. Nim Game 🎯

### Problem Overview
In this problem, two players take turns removing 1 to 3 stones from a pile. The player who removes the last stone wins. The task is to determine whether the first player can win if both players play optimally.

### Logic Used
This problem is based on pattern recognition:
- If the number of stones is a multiple of 4, the first player loses
- Otherwise, the first player can always make a move that leaves a multiple of 4 for the opponent
- This creates a winning strategy without needing loops or simulation

### What I Learned
- How mathematical patterns can simplify a problem
- Introduction to basic game theory thinking
- The importance of observation in problem solving
- How some problems can be solved in constant time using logic alone

### Takeaway
This problem taught me that not every solution needs iteration or brute force. Sometimes the answer is hidden in the pattern itself 🔍
